\section{第一个程序}

\subsection{写代码}

打开你的编辑器，新建一个文件，名字叫 \texttt{hello.c}，把下面几行抄进去：

\begin{codebox}{hello.c —— 第一个 C 程序}
#include <stdio.h>

int main(void)
{
    printf("你好，计算机！\n");
    return 0;
}
\end{codebox}

编译并运行后，屏幕上会出现：

\begin{outbox}{运行结果}
你好，计算机！
\end{outbox}

恭喜，你已经写出第一个程序了！下面我们一行一行看，它到底在说什么。

\subsection{逐行解释}

\subsubsection*{第一行：\texttt{\#include <stdio.h>}}

这一行是“借工具箱”。

\texttt{stdio} 是“标准输入输出”的缩写。我们马上要用到的 \texttt{printf}（在屏幕上打印）就放在这个工具箱里。写这一行，相当于告诉计算机：“我要用这个工具箱里的东西。”

\begin{tipbox}[暂时不用深究]
你现在只要记住：\textbf{只要用到 \texttt{printf} 或 \texttt{scanf}，开头就写这一行}。为什么、怎么找到工具箱的，以后会慢慢明白。
\end{tipbox}

\subsubsection*{第三行：\texttt{int main(void)}}

这一行是程序的“大门”。

计算机运行程序时，会先找到 \texttt{main}，从它后面的花括号开始，一句一句往下执行。

\begin{itemize}
  \item \texttt{main} 是固定的名字，不能改；
  \item \texttt{int} 表示程序结束时会给计算机一个整数；
  \item \texttt{(void)} 表示这个程序不需要从外面接收参数。
\end{itemize}

\subsubsection*{花括号 \texttt{\{ \}}：范围}

花括号里的内容，是这个程序要做的所有事情。就像写作文的“正文部分”。

\subsubsection*{第五行：\texttt{printf("你好，计算机！\textbackslash n");}}

这一行让计算机“说话”。

\begin{itemize}
  \item \texttt{printf} 是打印函数，负责把双引号里的内容显示到屏幕上；
  \item 双引号里的文字，会原样显示；
  \item \texttt{\textbackslash n} 表示“换行”，不是两个普通字符；
  \item 最后的分号 \texttt{;} 表示“这句话说完了”，相当于中文的句号。
\end{itemize}

\begin{pitfall}[分号不能少]
C 语言的每条语句后面都要有分号。少一个分号，编译器就会报错。分号必须是英文的 \texttt{;}，不能是中文的 \texttt{；}。
\end{pitfall}

\subsubsection*{第六行：\texttt{return 0;}}

这一行告诉计算机：“程序正常结束了。”

0 表示“一切正常”。如果程序出了问题，可以返回别的数字，但对初学者来说，先固定写 \texttt{return 0;} 就好。

\subsection{程序的基本骨架}

把上面的程序缩成一幅图，就是：

\begin{center}
\begin{tikzpicture}[x=1cm,y=1cm,node distance=4mm]
  \node[box,minimum width=8cm,align=left,font=\ttfamily\small] (a) {\#include <stdio.h>};
  \node[box,minimum width=8cm,align=left,font=\ttfamily\small,below=of a] (b) {int main(void)};
  \node[box,minimum width=8cm,align=left,font=\ttfamily\small,below=of b] (c) {\{ 要做的事情 \}};
  \node[lbl,right=3mm of a] {借工具箱};
  \node[lbl,right=3mm of b] {程序大门};
  \node[lbl,right=3mm of c] {程序内容};
\end{tikzpicture}
\end{center}

\begin{c89box}[写代码的三个好习惯]
\begin{enumerate}
  \item 花括号单独占一行，里面的语句往右缩进 4 个空格；
  \item 每条语句后面写英文分号；
  \item \texttt{main} 写成 \texttt{int main(void)}，结尾写 \texttt{return 0;}。
\end{enumerate}
\end{c89box}

\section{变量：给数据准备一个盒子}

\subsection{什么是变量}

变量就是一个“贴了名字的盒子”，里面可以放数据。

\begin{center}
\begin{tikzpicture}[x=1cm,y=1cm]
  \node[draw=structurecolor!70,fill=structurecolor!7,rounded corners=2mm,
        minimum width=3cm,minimum height=1.5cm,align=center] (box) at (0,0)
    {盒子\\[2pt]\ttfamily 10};
  \node[font=\small,above=2mm of box] {名字：\texttt{a}};
  \node[font=\small,below=2mm of box] {类型：\texttt{int}（装整数）};
\end{tikzpicture}
\end{center}

写程序时，我们这样使用它：

\begin{codebox}{variable.c —— 变量的声明和赋值}
int a;          /* 准备一个盒子，名字叫 a */
a = 10;         /* 把 10 放进盒子里 */
\end{codebox}

也可以把两步合成一步：

\begin{codebox}{variable2.c —— 声明时直接放值}
int a = 10;     /* 准备盒子 a，并放入 10 */
\end{codebox}

\subsection{变量的类型}

盒子有不同的大小，能装的东西也不一样。C 语言里常用的类型有三种：

\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
类型 & 能装什么 & 例子 \\
\midrule
\texttt{int} & 整数 & 0、5、-3、100 \\
\texttt{double} & 小数 & 3.14、0.5、-2.75 \\
\texttt{char} & 一个字符 & 'A'、'x'、'5' \\
\bottomrule
\end{tabular}
\end{center}

\begin{itemize}
  \item \texttt{int} 是 \en{integer}（整数）的缩写；
  \item \texttt{double} 表示双精度小数，可以理解为“更精确的小数”；
  \item \texttt{char} 是 \en{character}（字符）的缩写。
\end{itemize}

\begin{tipbox}[先只用这三种]
初学阶段，整数用 \texttt{int}，小数用 \texttt{double}，单个字符用 \texttt{char}，足够用了。其他类型以后需要再学。
\end{tipbox}

\subsection{变量名怎么起}

变量名要遵守几条规则：

\begin{itemize}
  \item 只能用字母、数字、下划线；
  \item 不能以数字开头；
  \item 区分大小写，\texttt{a} 和 \texttt{A} 是两个不同的变量；
  \item 不能用 C 语言的关键字，例如 \texttt{int}、\texttt{return}。
\end{itemize}

起名字要让人一看就懂：

\begin{center}
\begin{tabular}{@{}ll@{}}
\toprule
好名字 & 不好的名字 \\
\midrule
\texttt{age}、\texttt{score}、\texttt{sum} & \texttt{a}、\texttt{b}、\texttt{x1} \\
\texttt{max\_value}、\texttt{student\_num} & \texttt{abc}、\texttt{tmp1} \\
\bottomrule
\end{tabular}
\end{center}

\subsection{C89 的声明规则}

C89 规定：\textbf{一个花括号里，所有变量都要先声明，再写其他语句。}

正确的写法：

\begin{codebox}{declare-ok.c —— 先声明，后使用}
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = 5;
    int sum;

    sum = a + b;
    printf("%d\n", sum);
    return 0;
}
\end{codebox}

错误的写法：

\begin{codebox}{declare-bad.c —— 声明写在了后面}
#include <stdio.h>

int main(void)
{
    int a = 3;

    printf("%d\n", a);

    int b = 5;      /* 错误：声明不能写在语句后面 */
    printf("%d\n", b);
    return 0;
}
\end{codebox}

\begin{c89box}[记住这句话]
\textbf{变量声明全部写在花括号开头，后面才写执行语句。}后面学 \texttt{for} 循环时，循环变量也要提前声明，不能写在 \texttt{for} 里面。
\end{c89box}

\section{输出：让计算机说话}

\subsection{用 \texttt{printf} 输出}

\texttt{printf} 可以输出文字，也可以输出变量的值。

\begin{codebox}{printf1.c —— 输出文字和数字}
#include <stdio.h>

int main(void)
{
    int age = 18;

    printf("我今年 %d 岁\n", age);
    return 0;
}
\end{codebox}

\begin{outbox}{运行结果}
我今年 18 岁
\end{outbox}

这里的 \texttt{\%d} 是一个“占位符”，意思是“这里要放一个整数”。后面的 \texttt{age} 会填到这个位置。

常用的占位符：

\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
占位符 & 用来输出 & 例子 \\
\midrule
\texttt{\%d} & 整数 & \texttt{printf("\%d", 10);} \\
\texttt{\%f} & 小数 & \texttt{printf("\%f", 3.14);} \\
\texttt{\%.2f} & 保留两位小数 & \texttt{printf("\%.2f", 3.14159);} 输出 3.14 \\
\texttt{\%c} & 一个字符 & \texttt{printf("\%c", 'A');} \\
\texttt{\%s} & 字符串 & \texttt{printf("\%s", "你好");} \\
\bottomrule
\end{tabular}
\end{center}

\begin{pitfall}[占位符和类型要对应]
整数用 \texttt{\%d}，小数用 \texttt{\%f}。用错了可能输出奇怪的结果。比如用 \texttt{\%d} 输出小数，就是不对的。
\end{pitfall}

\subsection{换行}

\texttt{\textbackslash n} 表示换行。没有它，下一次输出会接在同一行后面。

\begin{codebox}{newline.c —— 换行的效果}
#include <stdio.h>

int main(void)
{
    printf("第一行\n");
    printf("第二行\n");
    return 0;
}
\end{codebox}

\begin{outbox}{运行结果}
第一行
第二行
\end{outbox}

\section{输入：让计算机听我们说话}

\subsection{用 \texttt{scanf} 读入}

如果想让用户输入数字，就用 \texttt{scanf}。

\begin{codebox}{scanf1.c —— 读入一个整数}
#include <stdio.h>

int main(void)
{
    int a;

    printf("请输入一个整数：");
    scanf("%d", &a);

    printf("你输入的是 %d\n", a);
    return 0;
}
\end{codebox}

\begin{outbox}{运行示例}
请输入一个整数：7
你输入的是 7
\end{outbox}

注意 \texttt{scanf} 里面写的是 \texttt{\&a}，不是 \texttt{a}。这个 \texttt{\&} 读作“取地址”。

\begin{tipbox}[为什么 \texttt{scanf} 要加 \texttt{\&}？]
\texttt{scanf} 要把读到的数字放进变量 \texttt{a} 的盒子里，所以它需要知道盒子在哪里。\texttt{\&a} 就是“盒子 a 的地址”。现在先照写，等学指针时会彻底明白。
\end{tipbox}

\subsection{读入两个数}

\begin{codebox}{scanf2.c —— 读入两个整数}
#include <stdio.h>

int main(void)
{
    int a, b;

    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);

    printf("a = %d, b = %d\n", a, b);
    return 0;
}
\end{codebox}

\begin{outbox}{运行示例}
请输入两个整数：3 5
a = 3, b = 5
\end{outbox}

两个 \texttt{\%d} 连在一起，输入时用空格或回车隔开都可以。

\section{顺序结构：一步一步来}

顺序结构就是程序从上往下，一句一句执行。大部分小程序的套路都是：

\begin{center}
\begin{tikzpicture}[x=1cm,y=1cm,node distance=12mm]
  \node[box] (in) {输入数据};
  \node[box,right=of in] (calc) {计算};
  \node[box,right=of calc] (out) {输出结果};
  \draw[flow] (in) -- (calc);
  \draw[flow] (calc) -- (out);
\end{tikzpicture}
\end{center}

下面用几个例子练一练。

\subsection{例：两数之和}

\begin{example}
输入两个整数，输出它们的和。
\end{example}
\begin{solution}
\begin{codebox}{sum.c —— 两数之和}
#include <stdio.h>

int main(void)
{
    int a, b, sum;

    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);

    sum = a + b;
    printf("和是 %d\n", sum);
    return 0;
}
\end{codebox}

\begin{outbox}{运行示例}
请输入两个整数：3 5
和是 8
\end{outbox}
\end{solution}

\subsection{例：长方形的面积}

\begin{example}
输入长和宽，输出长方形的面积。
\end{example}
\begin{solution}
\begin{codebox}{rectangle.c —— 长方形面积}
#include <stdio.h>

int main(void)
{
    double length, width, area;

    printf("请输入长和宽：");
    scanf("%lf%lf", &length, &width);

    area = length * width;
    printf("面积是 %.2f\n", area);
    return 0;
}
\end{codebox}

\begin{outbox}{运行示例}
请输入长和宽：3.5 2
面积是 7.00
\end{outbox}

\texttt{scanf} 读 \texttt{double} 时用 \texttt{\%lf}，输出时用 \texttt{\%f} 或 \texttt{\%.2f}。先记住这个区别。
\end{solution}

\subsection{例：求平均分}

\begin{example}
输入三门课的成绩，输出平均分，保留两位小数。
\end{example}
\begin{solution}
\begin{codebox}{average.c —— 平均分}
#include <stdio.h>

int main(void)
{
    double a, b, c, average;

    printf("请输入三门课成绩：");
    scanf("%lf%lf%lf", &a, &b, &c);

    average = (a + b + c) / 3.0;
    printf("平均分是 %.2f\n", average);
    return 0;
}
\end{codebox}

\begin{outbox}{运行示例}
请输入三门课成绩：80 90 100
平均分是 90.00
\end{outbox}
\end{solution}

\subsection{例：交换两杯水}

\begin{example}
有两个变量 \texttt{a} 和 \texttt{b}，怎样交换它们的值？
\end{example}
\begin{solution}
交换两杯水，需要第三个空杯子。交换两个变量，也需要一个临时变量。

\begin{codebox}{swap.c —— 交换两个变量}
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = 5;
    int temp;

    printf("交换前：a = %d, b = %d\n", a, b);

    temp = a;       /* 把 a 倒进空杯子 */
    a = b;          /* 把 b 倒进 a */
    b = temp;       /* 把空杯子里的 a 倒进 b */

    printf("交换后：a = %d, b = %d\n", a, b);
    return 0;
}
\end{codebox}

\begin{outbox}{运行结果}
交换前：a = 3, b = 5
交换后：a = 5, b = 3
\end{outbox}

这三步以后会经常用到，请记牢。
\end{solution}

\section{注释和好习惯}

\subsection{写注释}

注释是写给人看的，计算机不会执行。C89 用 \texttt{/* */} 包住注释：

\begin{codebox}{comment.c —— 注释}
#include <stdio.h>

int main(void)
{
    /* 这是一个变量，用来存年龄 */
    int age = 18;

    printf("%d\n", age);    /* 输出年龄 */
    return 0;
}
\end{codebox}

\begin{itemize}
  \item \texttt{/*} 和 \texttt{*/} 要成对出现；
  \item 注释可以写在一行里，也可以跨很多行；
  \item 注释是给自己和同学看的，写“为什么这样做”，不要写废话。
\end{itemize}

\begin{c89box}[C89 只用块注释]
C89 不支持 \texttt{//} 这种单行注释。本书所有代码都用 \texttt{/* */}。
\end{c89box}

\subsection{排版好习惯}

同样的程序，排版好会更容易看懂：

\begin{codebox}{style.c —— 好的排版}
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;
    int sum;

    sum = a + b;

    printf("sum = %d\n", sum);
    return 0;
}
\end{codebox}

\begin{itemize}
  \item 花括号单独占一行；
  \item 里面的语句缩进 4 个空格；
  \item 不同功能的代码之间空一行；
  \item 变量名起得有意义。
\end{itemize}

\section{常见错误}

初学阶段，90\% 的错误都是下面几种：

\begin{center}
\begin{tabular}{@{}p{0.38\textwidth}p{0.52\textwidth}@{}}
\toprule
错误 & 原因 \\
\midrule
少写分号 & 每条语句末尾要有 \texttt{;} \\
用了中文标点 & 中文的 \texttt{；，（）} 计算机不认识 \\
\texttt{printf} 拼错 & 大小写要一致，是 \texttt{printf} \\
\texttt{scanf} 忘了 \texttt{\&} & 应该写 \texttt{scanf("\%d", \&a);} \\
占位符用错 & 整数用 \texttt{\%d}，小数用 \texttt{\%f} \\
变量没赋值就使用 & 盒子里是垃圾数据 \\
变量声明写在语句后面 & C89 不允许，要全部提到开头 \\
\bottomrule
\end{tabular}
\end{center}

\begin{pitfall}[程序一闪而过]
在 Windows 上双击运行控制台程序，程序执行完窗口就关了，看起来“一闪而过”。这是正常现象。可以在最后加一句 \texttt{getchar();} 让程序等一下，或者从命令行运行。
\end{pitfall}
